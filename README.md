# laba-number-dva
Интерактивная веб-визитка, стилизованная под терминал. Проект представляет собой одностраничное веб-приложение (SPA) с командной строкой, анимацией фона и немного адаптивной версткой.

Посмотреть работающий сайт можно по ссылке:
https://accidia.fun

### Стек:
   **HTML5** — семантическая структура интерфейса.
   **CSS3** — стилизация (Flexbox, CSS-анимации, эффект «бинарного дождя», адаптивная верстка для мобильных устройств).
   **JavaScript** — вся логика приложения, работа с DOM, обработка событий ввода.
   **Canvas API** — отрисовка интерактивного фонового «матричного дождя».
   **Font Awesome** — иконки социальных сетей.
   **Google Fonts (VT323)** — моноширинный шрифт для стилизации под терминал.

### 1. Командная строка (Терминал)
Вся навигация по сайту осуществляется через ввод текстовых команд. Доступны следующие команды:
   `help` — выводит список доступных команд.
   `whoami` — выводит информацию о владельце визитки (имя, статус, email).
   `skills` — выводит стек технологий и навыков.
   `contacts` — открывает панель с кликабельными ссылками на соцсети (Telegram, VK, GitHub).
   `clear` — полностью очищает терминал и скрывает боковые панели.
   `reset` — сбрасывает фоновый «матричный дождь» до стандартного бинарного кода (0 и 1).

### 2. Интерактивный матричный дождь, реализованный Canvas
На фоне работает анимация падающих символов, которая адаптируется под пользователя:
   Изначально дождь состоит только из нулей и единиц.
   Скрипт считывает нажатия клавиш на клавиатуре(с мобильных устройств только при вводе в терминал). Каждая новая введенная буква или цифра добавляется в алфавит фонового дождя.
   Чем больше уникальных символов ввел пользователь, тем разнообразнее становится фоновый поток.

### 3. Дополнительно
   Звуковое сопровождение: При нажатии клавиши `Enter` воспроизводится тихий клик.
   Имитация загрузки: Команды выполняются с задержкой и анимацией точек (`...`), имитируя консоль.
